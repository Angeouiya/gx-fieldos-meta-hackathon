# Interface GX — Phase 3A-1

## Direction

Un atelier exécutif calme : grande surface lumineuse, conversation centrale,
sidebar compacte, typographie graphite et contraste construit par l’espace plutôt
que par des cartes. GX reste technologique, premium et universel, sans décor
agricole.

## Filiation AGRIX vérifiée en lecture seule

Source observée sans modification :

AGRIX's existing brand color tokens, observed in its stylesheet.

Couleurs de marque confirmées :

- vert forêt AGRIX : `#1B4332` ;
- vert intermédiaire : `#2D5A45` ;
- orange AGRIX : `#F7931E` ;
- orange sombre : `#E07C0C`.

L’orange reste un accent exceptionnel dans GX. Le shell emploie principalement
la filiation verte avec des surfaces neutres.

## Tokens GX

- `--gx-brand`, `--gx-brand-dark`, `--gx-brand-soft` ;
- `--gx-background`, `--gx-surface`, `--gx-surface-subtle` ;
- `--gx-text`, `--gx-text-secondary`, `--gx-border` ;
- `--gx-success`, `--gx-warning`, `--gx-danger`.

## Règles fondatrices

- aucun bouton « Accueil » : le logo GX ouvre la conversation vide ;
- largeur de sidebar : 228 px à 1366 px, 244 px au-delà de 1500 px ;
- zone conversationnelle dominante et centrée ;
- focus clavier visible et labels accessibles ;
- animations désactivées avec `prefers-reduced-motion` ;
- aucune grande carte, statistique, notification permanente ou panneau droit ;
- aucun élément agricole décoratif.
